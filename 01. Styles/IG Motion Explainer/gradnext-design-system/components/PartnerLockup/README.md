# PartnerLockup

gradnext set beside a partner brand with equal respect — neither logo dominates.

Provide `partner` (the partner's logo as an `<img>`, or its name), `layout` and a `height` that makes both logos optically equal.

- `divider` — a thin vertical rule between the logos.
- `cross` — a light "×" between the logos, for co-branded programmes.
- `stacked` — gradnext above a horizontal rule, partner below (or the reverse).
- Keep clear space around both; align them on a shared centre line. Never shrink the gradnext wordmark below the partner's visual weight.
