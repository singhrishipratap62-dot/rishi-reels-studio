# EDITING_PSYCHOLOGY (v1.0)
Reference only: SKILL.md wins on any conflict.
Script template (both refs follow it exactly) [OBS]:
1. Hook question "How do you price X?" → S1 (photo makes the object concrete; MBB logos = stakes).
2. "This is a real <firm> case interview." → S2 punch-in (eye contact, intimacy, credibility).
3. Client setup "Your client is … The <role> asks: '<question>'" → board full-card setup: photo/label/big numbers, then the root question box.
4. "This is how you'd solve it consultant style. Before jumping to a number, I'd ask clarifying questions…" → small heading text, then the tree label.
5. Each Q/A → one tree row (Q pill on the question, A pill on the answer) + a left-column visual of the answer's number.
6. Remaining facts (prices, costs, volumes) → added as tree rows + left visual.
7. "So how do we price it? I'd price it in N ways." → SOLVE phase, N tabs.
8. Each method → tab active, working in the middle, result to the number line ("That's our floor/ceiling" = marker lands).
9. Recommendation "I'd price it around ₹X" → answer marker + highlight; the justification (savings, margin) as stacked bar.
10. CTA "This is part N… Follow for part N+1" → S4 end card.

Selection framework per beat: function → first choice → alternates
- quantity with unit over time (5 years, 20 years) → years progress bar → number + label
- money amount → big ₹ number count-up → ₹ in tree row
- physical object (refill, device, car, road) → line icon → photo tile
- count of things (8 refills, 30 cr trips, 40,000 vehicles) → unit grid → big number
- cost build-up / split → stacked bar with labels → equation chips
- comparison A vs B → two boxes with "vs"/"≈" → bars
- time saved → clock icon filling → number
- unknown being asked → "? ? cr" placeholder box, filled when answered
- method result → chip "= ₹X" → marker on number line

Anti-patterns: two lines of caption; visuals not on the word; decorative motion; anything over the face; extra punch-ins; visual for a filler sentence; changing the root question wording.
Words in captions are the CORRECTED script (fix ASR: "flow"→"floor", "18-piece"→"80 rupees", "Upper Zay"→real city name) — confirm in plan.
