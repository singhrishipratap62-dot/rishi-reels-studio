# Rishi v2: editing-style pack

The notebook distilled from five style "books" (Minimal Edit Style, Rishi's Editing Style v1.3, Daniel Presley, Paper Stage / Azma, Claude Edits) plus roughcut_v3 drafts 1–4, vid2, vid5 and Style Lab v1. Entry point and **only mandatory read: `SKILL.md`** (every hard rule, number and compiled lesson). Everything else is opened only when SKILL.md's "Read only when…" table says so.
