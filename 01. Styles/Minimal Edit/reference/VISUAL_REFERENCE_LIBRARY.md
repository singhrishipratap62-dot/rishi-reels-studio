# Visual Reference Library — v1.0

## How the frames were captured (and limits)
- Tutorial (20:57, 1080p): 2 s sampling for 1:00–6:40 (principles), 6 s for 7:50–17:50 (training, planning, build), 2 s for the full-frame wrap-up, 1 s for the finished 57 s edit, and 6 fps strips for four animations. Scene-cut detection was run as a cross-check. Not every frame was viewed, so very short animations between samples may be missing.
- 7 reference reels (R1–R7, 720×1280): ~32 evenly spaced frames each, plus cut detection for pacing.
- Audio was **not** analysed, so sound notes come from the transcript and on-screen UI text only.
- Promotional sections (06:12–07:44, 11:06–11:42, 19:36–end) were skipped.
