# Stickers

Eight head stickers of Rishi: transparent WebP on a 1280 px square canvas, same scale and paper border. Names: `head-neutral`, `head-skeptical`, `head-thinking`, `head-confused`, `head-smirk`, `head-laughing`, `head-shocked`, `head-concerned`.

Which one to use, how often, where and how it moves: see the *Stickers* section of the brand book. Never recolour, add a shadow, rotate or crop them.
