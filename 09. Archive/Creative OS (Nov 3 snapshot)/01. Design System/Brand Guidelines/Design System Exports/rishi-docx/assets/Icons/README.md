# Icons

Isometric line icons drawn in rishi.docx's pen-and-grid style: 4px ink lines with rounded joins, standing on a flat signal-tint plate. Single-ink: the line colour is `brand-ink` (#141414) and the plate is `signal-marker`. These files are the paper-theme version; on the ink theme, draw the same paths inline with the line colour set to `brand-paper`.

- `model` — an AI model, a system, "the black box"
- `document` — a paper, policy, report, prompt file
- `server` — compute, GPUs, data centre, the backend
- `browser` — a website, app or web tool
- `person` — a user, a worker, a creator
- `rupee` — money, salary, cost (LPA/₹ stories)

Rules: icons label and decorate a diagram node or a card; they never replace a word. One plate colour only. Minimum size 96px on a 1080 canvas. Pop in with Settle (`dur-quick`) — scale from 80%.
