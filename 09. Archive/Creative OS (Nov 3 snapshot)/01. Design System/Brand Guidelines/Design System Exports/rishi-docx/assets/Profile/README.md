# Profile

Rishi's profile photo, used in place of a logo until one exists.

- `rishi-avatar.webp` — 640×640 face crop, ready for a circle. Use this in the FollowCard and anywhere the account itself appears (a mock Instagram post, a comment, a profile header).
- `rishi-profile-original.jpg` — the original 800×800 photo, for re-cropping.

Always show it as a circle (Instagram's avatar shape), never squared, stretched, recoloured or filtered. Minimum size on a 1080 canvas: 160px.
