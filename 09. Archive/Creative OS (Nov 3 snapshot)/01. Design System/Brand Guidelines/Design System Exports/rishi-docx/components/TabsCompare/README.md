# TabsCompare

One frame with a row of tabs; each tab switches the frame to a different version.

**Use for:** "original / green screen / replaced", model A vs B vs C on the same prompt, three settings on the same image.

**Anatomy:** hairline frame → tab row under it: square tabs in Semibold 32px, uppercase, 2px `line-strong` borders; active tab filled `ink` with `bg` text.

**Motion:** the active tab moves on the voice; the frame swaps instantly (or with a 100ms cross-fade).

**You provide:** the versions and their tab names.
