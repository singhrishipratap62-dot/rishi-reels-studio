# SourceCard

A small card naming where a fact comes from.

**Use for:** every factual claim on screen — numbers, quotes, events.

**Anatomy:** 4px `ink` top rule over a `surface` card → `label` "SOURCE" → source name in `body` Medium → date and source type in `caption`.

**Motion:** slides in from the left 40px (Enter easing, 250ms) while the fact is on screen, exits with it.

**Rules:** always the real source, named specifically (company blog, filing, court document, publication). Inside the safe area. Never a URL.

**You provide:** the source name, date and type.
