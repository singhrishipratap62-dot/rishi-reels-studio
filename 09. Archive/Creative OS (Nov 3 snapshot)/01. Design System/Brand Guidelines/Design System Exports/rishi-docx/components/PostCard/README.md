# PostCard

A recreated tweet, post or news article, with the line that matters highlighted and the rest dimmed.

**Use for:** "here's what X posted", a headline, a statement, a report excerpt.

**Anatomy:** floating card with `shadow-float`, 20px radius → author row (avatar circle, name in Semibold, handle and date in `ink-muted`) → body in 42px `ink-muted` → the key line in `ink` with a `signal-marker` sweep → `caption` source line below the card.

**Motion:** card eases in → key line highlight sweeps when it's read out (Key line level; step up to The point for the single phrase that matters) (Draw, matched to speech) → optional `Callout` on a phrase.

**Rules:** only real posts and articles, quoted exactly; mark it "recreated from" with the source. Don't fake engagement numbers.

**You provide:** the exact text, author, date and source.
