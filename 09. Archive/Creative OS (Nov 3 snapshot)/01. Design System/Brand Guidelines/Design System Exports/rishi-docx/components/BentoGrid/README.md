# BentoGrid

A grid of numbered option cards where the one being discussed gets the signal outline and the rest go ghost.

**Use for:** overviews ("4 ways") and then jumping between them; comparing options.

**Anatomy:** 2×2 (or 2×3) square-cornered `surface` cards, 24px gaps → number in 80px Semibold, name in 40px Medium at the bottom → selected card: 6px `signal` outline, ink text; others `ink-ghost` text.

**Motion:** cards stagger in (80ms) → the selection outline appears on the word that names it → move the selection as the reel moves through the options.

**You provide:** the options in order.
