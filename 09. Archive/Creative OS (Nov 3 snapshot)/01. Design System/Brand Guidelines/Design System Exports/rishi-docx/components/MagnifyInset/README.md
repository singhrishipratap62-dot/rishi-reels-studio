# MagnifyInset

A circle on a detail, connected by a hairline to an enlarged inset of that detail.

**Use for:** "look here" moments — a detail in a screenshot, an artefact in an image, small text in a document.

**Anatomy:** source image in a hairline frame → `signal` circle ring (5px) on the detail → 3px `signal` connector → inset with 5px `signal` border showing the detail at 2–4×.

**Motion:** ring pops in (200ms) → connector draws (150ms) → inset grows open (250ms). Hold while explained.

**Rules:** counts as the frame's signal moment. One magnifier per frame.

**You provide:** the image and the detail to zoom.
