# LowerThird

The name and role of a person or organisation on screen.

**Use for:** introducing people in a story, or labelling yourself on camera.

**Anatomy:** name in `title` Semibold → short `signal` rule (120px × 4px) → role in `caption`, `ink-muted`.

**Motion:** name rises in, rule draws out, role fades in. Holds 2–3s, exits fast.

**Rules:** above `safe-bottom` (420px from the bottom) and left of `safe-right`. Over footage, place it on a `bg` card, never floating on a busy shot.

**You provide:** the name and role.
