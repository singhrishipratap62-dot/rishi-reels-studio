# StatReveal

A single important number that counts up, with its unit, one line of context and its source.

**Use for:** any number that carries the story — a percentage, a rupee amount, a multiple, a count of people.

**Anatomy:** `label` → number at 200–260px, Semibold, tracking -3% → unit/context line in `headline` (an italic signal phrase allowed) → `line-strong` rule → `caption` source line.

**Motion:** number rises in and counts up over 800–1200ms (ease-out), context line follows 250ms later, rule draws across, source fades in last.

**Rules:** one number per frame. Use rupees and LPA for Indian audiences, not dollars (convert and say so in the source line). Never show a number without a source.

**You provide:** the number, unit, context line and the source (name + date).
