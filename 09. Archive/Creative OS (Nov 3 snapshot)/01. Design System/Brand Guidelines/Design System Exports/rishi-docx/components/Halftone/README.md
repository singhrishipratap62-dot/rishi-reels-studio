# Halftone

The illustration style: bold ink line drawing with halftone dot shading, plus one area dotted in signal.

**Use for:** objects and scenes that need more than an icon — a device, a building, a document stack, a hero object for a chapter.

**Anatomy:** 5px ink outlines on an isometric grid → shaded faces filled with ink halftone dots at a 14px pitch, rotated 30° (darker face: bigger dots, lighter face: smaller dots, lit face: plain `bg`) → one detail dotted in `signal` → optional ornaments (a four-point star, a crosshair).

**Motion:** eases in as one piece (Smooth, `dur-normal`), or builds face by face with the voice. Never rotates or floats.

**Rules:** no gradients, no realistic rendering, no colour fills beyond the single signal area.
