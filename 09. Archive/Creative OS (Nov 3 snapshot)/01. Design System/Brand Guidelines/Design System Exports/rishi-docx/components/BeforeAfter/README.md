# BeforeAfter

Two states side by side with a pen arrow drawn between them.

**Use for:** then vs now, input vs output, old way vs new way, manual vs AI.

**Anatomy:** two equal tiles with `label` headings (BEFORE / AFTER) → "before" on `surface`, "after" on `ink` (or two framed images) → `body` Semibold caption under each → curved pen arrow from before to after.

**Motion:** before eases in → arrow draws (300ms) → after eases in. For images, a hairline scan-line wipe across one frame (300–500ms) also works.

**You provide:** both states and their labels.
