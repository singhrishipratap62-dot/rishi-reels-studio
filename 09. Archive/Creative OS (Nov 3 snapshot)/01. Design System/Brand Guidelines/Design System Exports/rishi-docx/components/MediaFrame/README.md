# MediaFrame

Real footage or photos framed as evidence: hairline border, corner ticks, a tiny uppercase label.

**Use for:** clips of people, events, products, places — anything real shown as proof.

**Anatomy:** 2px `line-strong` frame with 20px inner padding → 4px `ink` corner ticks → label above the top-left in Semibold 28px, letter-spaced (`THE COMPANY`, `ACTOR`, `2019`) → optional serif-italic micro-caption under it.

**Motion:** frame eases in (200ms), footage pushes in slowly (1.0 → 1.08) while it holds. Several frames can build into a timeline or grid, one per sentence.

**Rules:** the label is a fact (name, year, role), not commentary. Use with a `SourceCard` when the origin matters.

**You provide:** the clip and the label.
