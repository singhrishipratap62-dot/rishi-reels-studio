# PenMarks

Hand-drawn marks in signal red that point at what matters: underline, arrow, strike-through and tick. No circles.

**Use for:** directing attention inside a frame — the key word, the key number, the step that matters, the myth (strike) and the reality (tick).

**Anatomy:** a single SVG path, `stroke: signal`, `stroke-width: stroke-pen` (10px at 1080), round caps and joins, slightly irregular so it reads as hand-drawn.

**Motion:** always drawn on as one stroke (stroke-dashoffset), Draw easing, `dur-normal`, starting 150ms after the thing it marks has landed. Never popped on, never animated in a loop in the final video.

**Rules:** no pen circles anywhere (retired October 2026): words get a highlight (see *Highlights* in *Pen and grid*); objects get a red-tint wash or the marching dotted square (see *Taste rules*). Max one or two marks per frame. A pen mark is the frame's signal moment. The pen marks things; it never writes words.

**You provide:** what to mark and which mark fits (see the table in *Pen and grid*).
