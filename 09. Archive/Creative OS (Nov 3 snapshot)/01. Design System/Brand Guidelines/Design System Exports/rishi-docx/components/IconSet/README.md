# IconSet

The rishi.docx icon set: isometric line icons standing on a flat signal-tint plate.

**Use for:** labelling diagram nodes, cards, prompt boxes and chapter dials — model, document, server, browser, person, rupee. Files are in the `Icons` asset group.

**Anatomy:** 4px ink lines, rounded joins, drawn on an isometric (30°) grid → a `signal-marker` rhombus plate under each icon.

**Motion:** pop in from 80% scale with Settle (`dur-quick`), staggered 80ms when several arrive.

**Rules:** icons support a word, never replace it. Min 96px on a 1080 canvas. On the ink theme, redraw the same paths inline with `brand-paper` lines. New icons follow the same grid, stroke and plate.
