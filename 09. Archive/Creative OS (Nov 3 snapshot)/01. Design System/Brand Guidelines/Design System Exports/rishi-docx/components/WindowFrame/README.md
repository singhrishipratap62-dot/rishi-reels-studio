# WindowFrame

Browser, app and terminal windows that hold real websites, code, tools and screen recordings.

**Use for:** any website, product, codebase or command line shown in a reel.

**Anatomy:** card with a 56px title bar in `surface`, three hollow circles (`ink-muted` outlines — neutral, not traffic-light colours), optional URL pill → content (screenshot, recording, or code in a monospace system font with `signal-marker` on the key line). Terminal variant: `brand-ink` body, paper text. 16px radius, `shadow-float`.

**Motion:** window eases in (200ms); several windows stagger 100–400ms and can multiply into a grid. Code types or lines highlight with the voice. Slow push-in (1.0 → 1.08) while it holds.

**Rules:** crop screen recordings tight and zoom in on the action; keep the cursor visible. Max two windows overlapping.

**You provide:** the screenshot/recording or code, and the URL label.
