# OverlayTile

One approved colour-overlay pairing: a rounded square fill centred on a rounded square ground.

Provide `ground`, `fill` and `size`. Only these seven pairings are approved:

| ground | fill |
| --- | --- |
| `dusk` (background-01) | `yellow`, `white` |
| `white` | `yellow`, `periwinkle` |
| `mist` (white, periwinkle corners) | `midnight` |
| `night` (rhino-950, periwinkle glows) | `yellow`, `periwinkle` |

Use it for app-icon style tiles, feature markers and section icons. Pass `label` when it carries meaning. Don't invent other pairings (e.g. periwinkle on dusk, yellow on mist).
