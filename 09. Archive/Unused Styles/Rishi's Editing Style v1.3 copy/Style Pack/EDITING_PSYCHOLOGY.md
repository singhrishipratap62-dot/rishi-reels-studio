# EDITING_PSYCHOLOGY — Rishi's Editing Style v1.0

Why the style works and how to decide beats. Rules are inferred from the 15 reference reels [INF] unless tagged. Numbers come from SYNTHESIS.md.

## 1. The core loop: claim → proof → face
1. The speaker states a claim on the face (trust).
2. Within 0-2 s an artifact proves it (UI card, counter, demo). Ideally the artifact is already landing as the key word is spoken [MEAS trigger offsets: −10…+10 f; numbers up to 2.4 s early].
3. The payoff or "so what" returns to the face.
The viewer never has to *believe*; they see. The face keeps it personal.

## 2. Hook (0-3 s, dense until ~10 s)
- Open on the face or on proof at frame 0. No intro card, no logo.
- Hook types that recur:
  - **Counted promise**: "3 mistakes…", "6 pillars…" + a visible tracker. This opens a loop the viewer wants closed.
  - **Number first**: a counter already running at frame 0 ($282,000), so proof comes before the claim.
  - **Person + result**: avatar + "$3,000/month", then a contrast fact ("never opened Premiere a year ago").
  - **Provocative question**: "Is editing dead?" as its own type beat.
- Density: 10-14 visual changes in the first 10 s [EST from rows], against 7-9 per 10 s later.

## 3. Body: rhythm and variety
- Alternate face ↔ graphic by **idea**, not by a fixed pattern. Never more than two graphic scenes without a face return.
- **Each chapter gets a different scene vocabulary** (card + split → meter + eye → swatches + logos in V02). The structure repeats; the visuals do not.
- **One idea per frame.** A frame carries one claim, one artifact and one emphasis colour.
- **Escalation**: later steps get bigger proof (1 tile → card + ghost wall → card + 16-card wall in V13). Scale of the visual = size of the claim.
- **Literal demonstration** beats explanation: if you can perform the rule on screen, do it.
- Holds: nothing static for more than ~3 s; a long hold gets a slow push.

## 4. Proof psychology
| device | effect |
|---|---|
| exact numbers ($727 → $800, 225 → 169 px) | specific = believable |
| real UI (post, Stripe toast, job post, DM) | the viewer recognises the interface, so it reads as fact |
| walls of cards | volume = credibility; "everyone else is doing this" |
| counters running ahead of speech | the proof arrives before doubt can form |
| before/after pairs (cheap vs premium profile, garage $50 vs showroom $500) | the difference is seen, not described |
| the doubt shown as UI (comment toasts "is this AI?") | names the viewer's objection, then answers it |

## 5. Emphasis economy
- **One emphasis per frame**: the italic word, the red mark, or the green number, never all three.
- The italic word goes on what the viewer should remember: the key noun, the qualifier, the emotional word.
- Red = urgency/negation only (hand-drawn ellipse/strike). Green = money only. Blue = badges, send buttons, glyphs. Rarity keeps them strong.
- Big type is rare: a giant word or a contrast line appears at most once or twice per reel, so it lands.

## 6. Pacing curve
| segment | visual changes per 10 s | cut rhythm | feel |
|---|---|---|---|
| hook (0-10 s) | 10-14 | fast | proof + promise |
| body | 7-9 | cut every ≈ 4-8 s, panes/cards between | steady teaching |
| climax/proof | one longer, calmer move (slow push, zoom) | — | let the key artifact breathe |
| CTA (last 5-8 s) | 4-6 | calm | one action, on the face or the action UI |
[EST: counted from timeline rows in 13 reels]

## 7. Sound psychology (pattern only; types not verified)
- Cuts mostly dry (median hit rate 0.18 [MEAS]). The edit is felt through motion, not punctuated by noise.
- Soft, long-attack cues sit under panes, card entrances, counters and keyword typing. Sound marks *new information*, not *new shot*.
- A cue on a chapter-opening cut is allowed (V15 pattern).

## 8. Offer/closing reels (when selling)
- Scarcity is said 2-3 ways early (caption, date/icon, red ellipse), then once more near the end as a clean type beat.
- The price is **drawn down** (strike + arrow + green), never just stated; or **hidden** (pixelated) to drive comments.
- The price appears before it is spoken, so it reads as no friction.

## 9. Decision checklist per beat (use in the edit plan)
1. What must the viewer feel or know here? (job)
2. Is there an artifact that proves it? → S4/S6. Can the rule be performed? → S3. Is it a quantity? → S5.
3. Does the speaker need to stay visible? → S2 split instead of full graphic.
4. Which single word/number is the emphasis? (italic / red / green, one only)
5. Does the visual land on or before the word?
6. Has the face been away for more than two scenes? → return to S1.
7. Is anything static for more than 3 s? → add a build, count or push.
