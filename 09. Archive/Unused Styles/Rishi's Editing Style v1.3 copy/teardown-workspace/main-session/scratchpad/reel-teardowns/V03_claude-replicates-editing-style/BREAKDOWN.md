## 10. Editing psychology
- Rule: each step of the narrated workflow gets its own screen artifact (upload → chat prompt → counters → document → mosaic → question card); speaker returns between steps to keep trust. [INF]
- Evidence pattern: number first ("458", "6 hours"), then a wall of proof (mosaic / plan docs) = "volume = credibility". [INF]
- Tension → release: "can Claude replicate?" → "Yeah." in 2 s on a clean card; then A-roll reaction ("genuinely impressed"). [INF]
- Pacing: hook dense (5 changes in 12 s), middle workflow steps 3-10 s each, ending calm with CTA field. [OBS]
- UI text mirrors speech so the viewer can follow with sound off. [INF]
