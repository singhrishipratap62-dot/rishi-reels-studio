## 10. Editing psychology
| condition | action | reason [INF] |
|---|---|---|
| a doubt/claim from the audience ("is it AI?") | show it as UI toasts inside a phone frame | the viewer sees the exact comment they'd think |
| a step in the workflow is described | a real UI performing it (chip drop, typed prompt) | the viewer can replicate it |
| a quantity (10 videos, 50 thumbs) | grid fill in a diagonal wave | quantity = effort/credibility |
| an abstract result ("skill") | an icon + label over defocused A-roll | gives the abstraction a shape |
| the CTA | tutorial card + comment bar typing the keyword | literal instruction |
Pacing (visual state changes per 10 s [EST from §2 + A-lists]): 0-10 s: 11 (swipe, 3 toasts, cut, profile, cube, grid) · 10-20 s: 8 · 20-30 s: 8 · 30-40 s: 7 · 40-50 s: 8 · 50-55.7 s: 5. Hook is the densest (≈ 1 per 0.9 s); the whole reel stays ≈ 1 per 1.3-1.7 s.

## 11. Signature moves (self-contained recipes)
1. Footage → phone-frame card on blue ground: 100%→63% H in ≈ 0.93 s ease-out `cubic-bezier(.2,.9,.6,1)`, radius ≈ 8% W, caption above at y≈11% H.
2. Comment toasts stacked top of card: glass pill (rgba white .15, blur), slide-down 25 px + fade, stagger ≈ 0.7 s.
3. Diagonal-wave thumbnail grid: 5×10, delay 0.04 s·(row+col), scale .8→1 + blur 6→0, total ≈ 1.2 s; blur-out in 5 f.
4. Typed prompt in a Claude-style input with file chips that fly in and shrink (≈ 0.7 s) — text trails the word by ≈ 0.3-1 s.
5. Doc card on blue with title swap + page flip every ≈ 2 s (script word per title).
6. Hologram icon + label over a defocused A-roll (icon leads the word by ≈ 2 s).
7. Two grounds alternate (blue = "inputs/results", cream = "Claude working") and A-roll returns between them for ≈ 1-6 s.
8. Literal CTA: comment bar types the keyword with cursor click.
