# Quality Control Checklist v1.0
Score each 0/1. Ship at ≥ 14/16 with all ★ items passing.

1. ★ First frame shows a prompt or numbered list (no logo/title).
2. ★ Chrome colours limited to bg.app / bg.app-deep / surfaces + terracotta.
3. ★ Each demo is labelled (slash name or label stack).
4. Label stack = bold sans + italic serif.
5. ★ At least one animated number (views/stat/counter) per demo or per 5 s.
6. Progress counter present and increments (A: n/N; B: 01/NN).
7. Visual change every ≤ 2 s; demos 3.5–5.5 s (A).
8. Output card 80–82% width, radius ~36 px, centred (A).
9. Captions: ≤ 2 lines, word-at-a-time, one emphasised word.
10. Keyword emphasis = blue selection box (A) or yellow (B), not both.
11. ★ CTA card "Comment “WORD”" in final 3–4 s with proof grid/fan.
12. Text inside IG safe zone (no key text in bottom 340 px / right 140 px).
13. iOS realism: 9:41, keyboard during typing only, reply bar after send.
14. No emoji, no neon glow, no stock transitions.
15. Typography sizes match scale (CTA word ≥ 120 px @1080).
16. Side-by-side with R01-3.2 / R06-20.5: would a viewer believe it's the same creator?
