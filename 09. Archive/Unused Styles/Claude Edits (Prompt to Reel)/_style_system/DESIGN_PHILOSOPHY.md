# Design Philosophy — "Prompt-to-Reel" (v1.0)

## What the style is
A short-form vertical (9:16) reel language that **sells an AI capability by showing the prompt and then the payoff**. The viewer watches a command being typed inside a dark, warm, Claude-like app UI, then sees the generated visual explode out of that UI. Proof (view counts, before/after, numbered effect lists) is always on screen. Every reel ends with a comment-for-link CTA. See [[DESIGN_SYSTEM]] for tokens.

Two families share one DNA (CONFIRMED, 6/6 refs):
- **Family A — UI Showcase** (R01, R04, R05, R06): the whole frame *is* the phone app. Demos play inside an output card.
- **Family B — Effects Reel** (R02, R03): a talking head is the canvas; a persistent numbered "effects list" overlay ticks through ~1 effect per second.

## What it communicates
"One command → a professional result." Speed, abundance (16 / 24 / 6 skills), and social proof (millions of views). Tool-native, insider, slightly product-launch.

## Principles
1. **Prompt is the hook.** The first frame shows a slash command or a numbered list — never a logo or title card. (CONFIRMED)
2. **Show the mechanism, then the magic.** Type → send → "Animating with /x…" → reveal. (CONFIRMED, A)
3. **Dark, warm, quiet chrome; loud content.** UI is near-black warm grey; colour lives inside the output and in one terracotta accent. (CONFIRMED)
4. **Sans for facts, serif italic for flavour.** Bold grotesk headline + one italic serif phrase ("with Claude Code", "works", "recreate"). (CONFIRMED)
5. **Count everything.** Progress counters (1/3, 01/24), view counters that roll, numbered lists. (CONFIRMED)
6. **Every demo is labelled.** Lowercase slash-name or "<topic> explainer / with Claude Code". (CONFIRMED)
7. **One-second rhythm.** Something changes every ~1 s. (CONFIRMED via scene detection)
8. **Close on abundance.** CTA card + grid of every output shown. (CONFIRMED 6/6)

## Avoid
Bright/white UI chrome in Family A; multiple accent colours in chrome; centred title cards at the start; logos; long sentences on screen; static holds > 2 s; stock-template transitions (spins, page curls); emoji in UI text.
