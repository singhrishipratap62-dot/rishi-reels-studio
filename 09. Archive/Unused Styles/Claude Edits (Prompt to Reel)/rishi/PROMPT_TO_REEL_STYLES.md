## D. Structure devices (in every reel, no need to pick)

Typing the command on the compose screen · autocomplete chip · send + "Animating with /x…" status · header progress counter (n/N) · label stack ("<topic> explainer / with one prompt") · rolling view-count pill · proof grid / fanned carousel · "Comment WORD" end card.
