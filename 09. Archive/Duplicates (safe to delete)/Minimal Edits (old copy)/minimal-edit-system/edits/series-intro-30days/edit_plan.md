# 30 Days of Consulting Prep — series intro · edit plan (draft 1)

**Sources:** `30 Days of Consulting Prep/Raw  Videos/Version 1–4 raw.MOV`. All are 4K portrait (2160×3840 after rotation), from an iPhone. V1 is 60 fps, V2/V4 are 30 fps and V3 is 29.97 fps. Every version is conformed to 30 fps.
**Transcripts:** `transcript/transcript.md` (word table in ms), `transcript/words.json`, `transcript/v1–v4.srt`.
**Style:** Minimal Editorial v1.1 plus LESSONS_LEARNED: serif heroes on A-roll, word-by-word support, char-by-char impact text with blur, Instagram Reels safe zone, and a +1.2 %/s push on all A-roll.
**Build:** Tesseract 0.4.0. Output 1080×1920, 30 fps.
**Draft 1 deliverable:** one comparison reel, **V1 → V2 → V3 → V4**. Each version is edited fully with the same design language and preceded by a 1.0 s slate ("Version 1 · seated, 8.2 s"). That makes the comparison about script and delivery, not edit quality.
