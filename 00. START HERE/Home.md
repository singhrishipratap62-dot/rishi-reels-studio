## Working in Obsidian
- Link with `[[wikilinks]]`. Existing `SKILL.md` and `README.md` names repeat across styles, so link them by path: `[[01. Styles/Rishi Style v2/SKILL|Rishi v2 skill]]`.
- New notes use frontmatter: `type`, `style`, `reel` (R###), `status`, `tags`. Templates are in `00. START HERE/Templates/`.
- Don't edit `SKILL.md`, `plan.md` or exports for linking; hubs and backlinks do that.
