# gradnext brand: quick reference

The full design system is at `01. Styles/IG Motion Explainer/gradnext-design-system/`: `README.md`, `tokens.json`, `tokens.css` and fonts. Wordmark and Besley files are in `01. Styles/IG Motion Explainer/_brand-build/`. Open those only when building brand graphics. This page covers the rules that matter most.

## Name and logo
- The brand name is always lowercase: **gradnext**, even at the start of a sentence. Use sentence case for headings.
- The logo is a text-only wordmark. Always use the logo files; never retype it in a font.
  - `gradnext-wordmark-rhino.svg/png` goes on white or light grounds.
  - `gradnext-wordmark-white.svg/png` goes on rhino, rhino-950 or midnight.
- Clear space: the height of the wordmark's "e" on every side.
- Partner lockups: equal optical weight, separated by a thin rule or "×". Neither logo dominates.

## Core colours
| Token | Hex | Use |
|---|---|---|
| rhino | `#2e3558` | Primary: wordmark, headings on white, dark grounds |
| periwinkle | `#8c9dff` | Accent fills and glows, highlighted words on dark. **Never text on white** |
| chrome-yellow | `#ffa601` | CTAs, stripe motif, highlights on rhino. **Never text on white** |
| white | `#ffffff` | Light grounds; text on dark |
| rangoon-black | `#1a1a1a` | Long body text on white |
| rhino-950 | `#1b1f38` | Base dark background |
| midnight | `#0d1028` | Gradient stop, header ink |

Semitones (`rhino-500…950`, `periwinkle-100…600`, `chrome-yellow-100…400`) add depth to backgrounds and secondary elements only.
