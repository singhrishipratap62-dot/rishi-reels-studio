PHASE 4: PREVENT DUPLICATION AND DATA LOSS

Implement a safe copying strategy.

Before copying:

1. Check whether the destination already exists.
2. Check whether an equivalent resource is already present.
3. Identify potential filename collisions.
4. Preserve original filenames whenever possible.
5. Preserve the internal structure of projects and resources.
6. Record the source path for every copied item.

If two files have the same name but different contents, preserve both using clearly distinguishable names or separate source-specific subfolders.

Never assume that two files with the same filename are identical.

For important files, compare checksums before and after copying to verify integrity.

Maintain a manifest that records:

- Original file path.
- New Creative OS path.
- File type.
- Category.
- Whether it was copied, skipped or requires review.
- Reason for the categorization.
- Any relevant dependencies or notes.

The original directory must remain untouched throughout the entire process.
